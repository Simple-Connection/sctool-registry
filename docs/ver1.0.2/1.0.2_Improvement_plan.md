## 1. Purpose

Distribution `1.0.2` turns the already-approved `1.0.1` Registry contracts into an executable Simple Connection consumer path without redefining Registry producer/admission policy.

The end-to-end target is:

```text
signed/public Registry metadata
-> package/channel/version/target resolution
-> authenticated GitHub Release asset resolution
-> exact artifact retrieval
-> filename/size/SHA-256 verification
-> Simple Connection local install
-> single-active version activation/runtime reconcile
-> last-known-good rollback safety
```

Registry session authority remains in this repository even when implementation code is physically stored in `Kinirin/Simple-Connection`.

## 2. Fixed input contracts

`1.0.2` starts from the released `1.0.1` baseline at:



The initial implementation must consume these contracts as-is. A contract/schema/policy change requires a separately approved Registry work unit; Simple Connection must not invent a local variant.

## 3. Version branch rule

All Registry work for this distribution contract version remains on:

```text
dev/1.0.2
```

Do not create per-session Registry branches. Do not merge `dev/1.0.2` to `main` until every approved `1.0.2` session and version-level acceptance gate is complete.

## 4. Responsibility boundary

### Registry owns

- canonical metadata/access/delivery contract provenance;
- fail-closed consumer requirements derived from Registry contracts;
- evidence that the external consumer matches those contracts;
- Registry-owned schema/policy changes only when separately approved;
- `1.0.2` session and merge-gate state.

### Simple Connection owns

- desktop/runtime integration;
- local package storage and installation;
- active version selection;
- runtime reconcile;
- rollback behavior;
- IPC/renderer UX;
- migration away from the legacy personal canonical SCTool repository authority.

### Forbidden cross-ownership

Registry must not modify Simple Connection PTSIP classification/profile merely to complete this version. Simple Connection must not redefine Registry producer/admission/access contracts locally.

## 7. P1 objective

P1 must make Registry package descriptor schema `2.0.0` a typed, deterministic, fail-closed SCTool SDK consumer boundary.

It must cover:

```text
schemaVersion == 2.0.0
package id / publisher
defaultChannel -> channels -> versions
target key == platform + "-" + arch
content.filename / sha256 / size authority
delivery.type explicit dispatch
delivery.access.contract == registry-access-v1
locator.repository == Simple-Connection/sctool-artifacts
assetId positive JavaScript-safe integer
unsupported/malformed contract rejection
```

P1 does not download artifact bytes or install/activate packages.
